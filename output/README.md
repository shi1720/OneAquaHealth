## Demonstration film

The finished footage is **3 minutes 58 seconds**, 1920×1080, H.264. It records the real application's full report → plan → verification → action → recheck → resolution → export sequence. It is silent so Shivam can record the supplied narration in his own voice.

- [Captioned demonstration MP4](https://github.com/shi1720/OneAquaHealth/releases/download/v1.0.0/rill-demo-captioned.mp4): immediately reviewable with explanatory captions below the interface.
- [Clean demonstration MP4](https://github.com/shi1720/OneAquaHealth/releases/download/v1.0.0/rill-demo-clean.mp4): the version to use when adding narration.
- [Timed, word-for-word narration](video/voiceover-timed.md): the closest match to the footage.
- [Subtitles](video/rill-demo-captions.srt), [shot list](video/SHOT-LIST.md), and [video verification](video/VERIFICATION.md).
- [Actual synthetic FHIR export](video/demo-fhir-bundle.json) and [recording proof](video/recording-proof.json).

The MP4 files are distributed as release assets to keep the source repository lightweight. Local workspace originals are in `output/video/`. [Reproduction instructions](../scripts/video/README.md) describe the isolated recording pipeline. No real passwords or recovery keys appear in the film.

## Submission handoff

1. Review the working app and the captioned film.
2. Record the timed script and add the voice track to the clean MP4. Check the finished video remains within 3–5 minutes, then upload it to a host accepted by Devpost.
3. Complete permanent hosting and its HTTPS/persistence checks; do not present a temporary or unverified URL as production hosting.
4. Resolve the event's conflicting eligibility wording and complete participant/team registration using accurate personal information.
5. Add the verified demo URL, video URL, public repository, Track 2 selection, and final project description to Devpost before **1 October 2026, 09:30 IST**.

The source has been published; this package does not claim that Devpost submission, eligibility verification, a voice recording, or field validation has happened. Commercial pricing and the proposed pilot remain hypotheses.
